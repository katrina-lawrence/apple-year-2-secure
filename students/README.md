# Year 2 — Student Resources

Welcome to the Year 2 technical learning environment.

This folder contains the preparation guides, technical setup instructions, and learning resources you will need throughout the five-day program.

## Getting Started

Before your first session:

1. Review the [Technical Preparation Guide](technical-preparation.md) and install the required software and development tools.
2. Confirm that you can access the GitHub repository and required application files.
3. Review the [Daily Setup Guide](daily-setup.md) for instructions on accessing the appropriate application version for each workshop day.
4. Confirm that you can open and run the application in Xcode.
5. Download the **Student Activity Workbook** and keep a copy available throughout the program.

## Working with GitHub

Each workshop day uses a designated application branch.

Follow the daily setup instructions to access the correct starting point for each activity.

- Use the designated starter branch for each workshop day.
- Keep your changes in your own branch or fork.
- Do not push changes directly to shared starter branches unless instructed by your mentor.

## Technical Support

If you encounter installation issues, application build errors, or difficulties accessing the required resources, contact your mentor for assistance.
